# Что куда класть (корень репозитория = папка NotesApp)

Скопируйте с заменой в корень проекта NotesApp:

    .github/workflows/android.yml
    fastlane/Fastfile            <- впишите свой App ID вместо 1:ВАШ_ID_FIREBASE
    fastlane/Pluginfile
    Gemfile
    .gitignore                   <- заменяет старый (добавлены *.jks, .kotlin)
    app/build.gradle.kts         <- заменяет старый (добавлена подпись release)

Дальше:
1. Если нет gradlew:  gradle wrapper --gradle-version 8.9  (и закоммитить gradlew, gradlew.bat, gradle/wrapper/gradle-wrapper.jar)
2. keytool -genkeypair -v -keystore keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias notes
3. PowerShell: [Convert]::ToBase64String([IO.File]::ReadAllBytes("keystore.jks")) | Set-Clipboard
4. GitHub -> Settings -> Secrets and variables -> Actions, 5 секретов:
   ANDROID_KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD, FIREBASE_SERVICE_ACCOUNT (весь JSON)
5. Firebase: приложение com.example.notes, группа тестеров с alias qa-team.
6. git push в main  -> сборка + письмо тестеру.
7. Задание Б: git checkout -b release/1.1 ; git push -u origin release/1.1
   -> версия в build.gradle.kts поднимется автоматически (versionName=1.1, versionCode=номер запуска).
   После этого сделайте git pull, чтобы получить коммит бота.
8. Проверка "Failed": сломайте код, запушьте -> придёт письмо от GitHub.
